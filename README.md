# s88s8

Сайт lushii — диск `SS:\angel`. На главной надпись, мем и папки, внизу терминал: `cd mp3`, `cd ..`, `dir`, `cls`, `help`.
`star_cursive on` и `heart_cursive on` — за курсором сыплются звёздочки или сердечки, `off` выключает;
`light_star on` — у всех звёзд на сайте белое сияние. Музыкой можно управлять из терминала: `play`
(или `play sushi` — по названию), `pause`, `next`, `prev`, `np`. Ещё есть `date`, `time` и `whoami`.
Папка mp3 — плеер, внутри неё папки-плейлисты; work — лента с лабой 9 про эллиптические кривые.
Где ты — видно в адресе (`#mp3/liked`), так что работает «назад» и ссылка прямо на плейлист.

На телефоне главная идёт колонкой, а в mp3 — список и мини-плеер внизу; тап по нему раскрывает плеер во весь экран.
На экране блокировки и в шторке — название, обложка и кнопки (Media Session: Safari на iOS 15+, Chrome на Android).
Лента work на телефоне — одна колонка: заметки встают под кусками тетради, меню слева прячется.

## Треки

Плейлист — подпапка `tracks/`, трек — `Артист - Название.mp3`, обложка рядом — `.jpg` с тем же именем:

```
tracks/liked/lushii - sushi.mp3
tracks/liked/lushii - sushi.jpg
tracks/night/...
```

`liked` открывается сам и стоит первым, остальные плейлисты — по алфавиту. Список приходит одним запросом
к GitHub API (дерево ветки по умолчанию), без токена это 60 запросов в час на IP.

## Запустить у себя

Нужен любой локальный сервер: модули и надпись из `img/lushii.svg` через `file://` не грузятся.

```sh
python3 -m http.server 8000
```

Потом открыть http://localhost:8000.

## Проверки

Нужен Node 22 или новее.

```sh
npm ci
npm run check
```

Это ESLint, Prettier, проверка типов по JSDoc (`tsc`, только файлы с `// @ts-check`) и тесты (`node --test`).

## Что где

- `index.html`, `css/site.css` — главная, экран mp3 и терминал.
- `site.js` — связывает всё: адрес страницы ↔ экран.
- `paths.js` — папки как диск: разбор путей из команд и из адреса.
- `commands.js` — команды терминала; ответы на ошибки — как в русском cmd.
- `terminal.js` — сам терминал: ввод, история стрелками, Tab дописывает имя папки.
- `trails.js` — след за курсором из звёздочек и сердечек (один canvas поверх страницы).
- `exit.js` — что бывает, если набрать exit.
- `folders.js` — папки: на главной и плейлисты на экране mp3.
- `tracks.js` — плейлисты из дерева репозитория на GitHub.
- `player.js` — логика плеера: очередь, перемешивание, повтор, громкость.
- `player-view.js` — экран mp3: список, обложка со свечением, панель с кнопками.
- `work.js` — лента work: меню слева со звездой у текущего раздела и живая демка на кривой.
- `curve.js` — эллиптическая кривая по модулю p: сложение и удвоение точек, умножение на число.
- `img/lushii.svg` — надпись: контуры букв Cormorant Garamond, поверх нарисованы шипы, хвост и звёзды.
- `img/star.svg` — иконка вкладки, та же звезда; `favicon.ico` и `apple-touch-icon.png` — она же в пикселях.
- `tracks/` — плейлисты с треками, см. «Треки» выше.
- `img/work/` — куски тетради и рисунки для ленты work; чернила перекрашены в цвет текста, фон прозрачный.
